## Как проверять актуальное состояние

```bash
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest -q
python evaluation.py --output evaluation_report.json
streamlit run app.py
```

Перед изменением ML-признаков нужно проверить `model_schema.py`, переобучить
комплект модели и повторить независимую evaluation. Перед изменением правил
нужно обновить `rule_config.py` и регрессионные тесты.
